# 2. Création de marchés

Les marchés déclarent leurs paramètres, collatéraux et règles de valorisation. Les droits d’administration sont séparés des appels de trading afin de rendre les invariants lisibles.

Les noms de contrats, fonctions et fichiers sont à confronter directement au dépôt ; ce texte décrit le rôle architectural observé, sans certifier un déploiement ni un audit.
